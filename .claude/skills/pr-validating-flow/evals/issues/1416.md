# Deleting a user while offline crashes the app (#1416)

## Steps to reproduce

Debug build, with the device offline (airplane mode on).

1. Turn on airplane mode.
2. Sign up as a new user (any language, phone `5551230001`, name Ada Admin, take and approve the selfie) to reach the Dashboard.
3. Track → add a user (`5551230002`, Bob Builder), take the selfie, then back out to the Dashboard.
4. Settings → Delete account, pick Bob, tap Next and confirm.

**Expected:** Bob is deleted, the "Account Deleted" dialog shows, and closing it returns to Settings.

**Actual:** The app crashes with an `AmazonClientException` (Cognito can't be reached). Deleting the admin crashes the same way. Bob is removed locally before the crash.

## Cause

`UserSelectViewModel.deleteUser` (`userselect/UserSelectViewModel.kt`) calls `messageRepo.syncMessages()`. In it, `messageUploader.uploadMessages()` (`models/messages/MessagesRepo.kt`) is outside the try/catch, so the exception escapes on the main scope.
