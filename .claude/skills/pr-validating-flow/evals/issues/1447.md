# Process death on session note, wallet select or add wallet crashes the app (#1447)

## What happens

In an org whose capture setup flow has a session note or wallet select step, if Android kills the app in the background while the user is on session note, wallet select or add wallet, reopening it from recents crashes:

```
java.lang.IllegalStateException: CaptureSetupScope not open. Call open() before getData().
```

Navigation 3 restores the step's screen, but `CaptureSetupScopeManager` keeps the capture setup scope only in memory. `SessionNoteViewModel`, `WalletSelectViewModel` and `AddWalletViewModel` read it in `init`. (Add org had the same crash and was fixed on its own.)

## Steps to reproduce

1. `bash e2e/seed-org.sh -s <serial> session-note` (or `wallet-select`) to make an org with that setup step the current org.
2. Open the app, tap Track, pick the user, and go forward to the session note (or wallet select, or its add wallet) screen.
3. Press Home, kill the app (`adb shell am kill org.greenstand.android.TreeTracker.debug`, or "Don't keep activities"), and reopen it from recents.
4. The app crashes instead of showing the step again.
