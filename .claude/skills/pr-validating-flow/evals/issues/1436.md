# Logout before the power user loads leaves the power-user flag set (#1436)

## What happens

`SettingsViewModel` loads the power user in `init` (`userRepo.getPowerUser()`, a Room query) and caches it in `state.powerUser`. On logout it clears the flag only through that cached copy:

```kotlin
// SettingsViewmodel.kt, SettingsAction.Logout
currentState.powerUser?.let { userRepo.setPowerUserStatus(it.id, false) }
```

If the user confirms logout before that load returns, `state.powerUser` is still `null`. `setPowerUserStatus` is never called and `power_user` stays `1` in the database. The splash screen checks `getPowerUser()`, so the next person to open the app is treated as the previous power user.

## Steps to reproduce

1. Sign in as a power user.
2. Open Settings and confirm Logout before the power-user query has returned (most likely on a slow device or right after the app starts).
3. Reopen the app: it signs in as the previous power user instead of showing sign-up.
