# Reopening the app after Android kills it on Add org crashes (#1418)

## Steps to reproduce

Debug build, with the device offline (airplane mode on).

1. Sign up as a new user (any language, phone `5551230001`, name Ada Admin, take and approve the selfie) to reach the Dashboard.
2. Tap Track, pick the user, tap Next. Add org shows.
3. Press Home, then kill the process (`adb shell am kill org.greenstand.android.TreeTracker.debug`, or Developer options → Don't keep activities).
4. Reopen the app from recents.

**Expected:** Add org comes back (or the app falls back to the Dashboard), and Next continues to capture.

**Actual:** Crash: `IllegalStateException: CaptureSetupScope not open`.

## Cause

Navigation 3 restores Add org, but the capture setup scope only lived in memory. `AddOrgViewModel` init (`orgpicker/AddOrgViewModel.kt`) calls `CaptureSetupScopeManager.getData()` before any `open()` (`models/setupflow/SetupScope.kt`).
